# Source inventory and metadata sample

The module is the **Cavli C16QS** (LTE Cat 1bis, LGA). It has four public sources: three technical manuals and the official product page. Sources were verified on 14–15 November 2026, and each was opened, hashed and identified from its cover page and version-history table. The machine-readable registry is [`sources/manifest.json`](../sources/manifest.json). The export of what is actually indexed, including the passage metadata sample and the review queue, is [`outputs/source-inventory.json`](../outputs/source-inventory.json), regenerated by `python -m docintel inventory`.

Notes:

- **Access.** On 2026-11-14 the TME URL returned a Cloudflare browser check (HTTP 403) to scripted requests, so the file was saved through a normal browser download into `cache/inbox/`. A from-scratch scripted run on 2026-11-15 downloaded it directly with the identical SHA-256. Ingest tries the URL first, then falls back to a hash-matched inbox file. Browser checks are never bypassed.
- **Copyright.** The PDFs carry a Cavli copyright notice that forbids reproduction. They are downloaded at ingest time into the git-ignored `cache/` and are **not** bundled. Answers quote short passages with citations.
- **Third-party hosts.** I found no official Cavli download URL for the three manuals. Document identity was confirmed from the Cavli cover page, the running header and the version history, but the hosting is third-party. This is disclosed as a limitation.

## Simulated revision (labelled)

[`sources/simulated/c16qs-hardware-manual-5.4-SIMULATED.json`](../sources/simulated/c16qs-hardware-manual-5.4-SIMULATED.json) creates "5.4-SIMULATED" from the stored 5.3 text with two edits. It changes the reset pulse on p. 31 from 100–500 ms to **150–500 ms** and adds a version-history line. It is stored with `simulated = 1`, its URL is `simulated:…` rather than the real PDF, and every answer that cites it carries a "SIMULATED – not a Cavli publication" warning. It is applied only to a separate demo or evaluation database (`cache/demo-revision.sqlite`, `cache/eval-revision.sqlite`), never to the main index.
